# TL;DR：嵌入资源进 VFS

**要做何事**：agent 在 bash 虚拟工作区里像改文件一样改 Excalidraw、Dynamic，并可查看图片；工作区负责上传、换 URL、记版本，改动走正文提案审阅。

## 用户将所见

1. agent 用 `sed` 改 `/embeds/<blockId>.excalidraw` 里的文字。
2. 提案中出现新版图，文字尺寸已重算。
3. 接受提案；已发布文章不变，重新发布后才更新。
4. 该图各版本可按 `asset_key` 查出。

## 决策

| 题 | 定 |
| --- | --- |
| 机制 | 一套 VFS，删 dynamic 专用工具与预览卡片 |
| 映射位置 | admin 工作区中间件，不改 LiteXML |
| 上传时机 | 写入即上传 |
| 版本 | `file_references` 加 `asset_key` |
| 防误删 | 加 `draft_id`；上传后未保存期间受保护 |
| 图片 | 只读挂载；`view` 多模态查看；生图写入 VFS |
| 目录 | 接受时登记；只改 meta 直接写目录 |

## 须核对（设计者自定）

- 另加 `draft_id` 列（`ref_id` 会被检查点清空）
- 只映射本站存储域名
- 工具结果只带 URL，服务端编码 base64
- 既有嵌入首次改动时给旧文件行补 key

## 工作量

约 3–4 个工作日：映射层与写回 1.5 日；图片附件跨仓 1 日；迁移与孤立判断 0.5 日；Dynamic 改造与 skill 0.5–1 日。
