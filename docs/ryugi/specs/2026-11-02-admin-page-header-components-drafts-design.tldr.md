# TL;DR：管理页通栏页头 + 动态组件引用与清理 + 草稿页改版

完整设计：`2026-11-02-admin-page-header-components-drafts-design.md`
画板：https://ryugi.innei.dev/a/1g5jLVB6l5SbtgRZ0nZMe

## 做什么

1. `MasterDetailShell` 加一个通栏页头插槽：标题、筛选、操作、一行概况。
2. 动态组件页：每个组件、每个版本被谁引用；一键清理对话框。
3. 草稿页：换上通栏页头；右侧默认显示存储概览和清理建议；详情先看与发布版比改了什么；清理对话框新增「疑似测试稿」。

## 你会看到

1. 打开动态组件页：每行带「在用 · N 篇 / 仅草稿引用 / 未使用」徽章。
2. 点一个组件：预览下面是版本时间线，每个版本列出引用它的文章；没人用的旧版本旁边有删除按钮。
3. 点页头「清理 · 可释放 X」：对话框按类别列出可删项，安全项已勾选，草稿在用的标黄、不勾。
4. 确认后删除；服务端发现仍被引用的项会自动放回组件目录，并告诉你放回了哪些。
5. 打开草稿页：右侧直接显示占用、可释放空间和 4 条清理建议。
6. 点一篇草稿：先看「+3 段 · 改 5 段 · −1 段」和改动摘录。
