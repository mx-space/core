
## Hard constraints (non-negotiable, override anything above if they ever conflict)

### Text gate
No text of any kind by default: no letters, numerals, watermarks, logos, UI chrome, or pseudo-text glyphs. The "text" axis is always "none".

### Rejection list
Never produce: a dashboard, an infographic, a product UI screen, a sci-fi HUD, a colorful data visualization, a generic gradient blob, a photographic scene, character illustration, a collage, an aged/distressed zine, or a glossy 3D render.
